# ATM Simulator - Java

A simple console-based ATM Simulator built using Java to practice basic Java programming concepts.

## 🎯 Project Purpose

The purpose of this project is to understand how basic Java concepts can be combined to build a working console application.

The program allows the user to check balance, deposit money, withdraw money, and exit from the ATM.

## ✨ Features

- Check account balance
- Deposit money
- Withdraw money
- Check for insufficient balance
- Handle invalid menu choices
- Repeat the ATM menu until the user selects Exit

## 🧠 Concepts Used

- Variables and Data Types
- Scanner
- Operators
- If-Else
- Else-If
- Nested If
- While Loop

## 📚 What I Learned

While building this project, I learned:

- How to take user input using Scanner.
- How to use if-else conditions for different menu options.
- How to update the balance after a deposit or withdrawal.
- How to use nested if conditions to check sufficient balance.
- How to use a while loop to repeat the ATM menu.
- How multiple basic Java concepts work together in one program.

## 🚧 Difficulties I Faced

While developing this project, I faced a few challenges:

- Initially, I was confused about how to update the balance after depositing money.
- I had difficulty understanding how to repeat the ATM menu after completing an operation.
- I had to understand how to check whether sufficient balance was available before withdrawal.
- I faced a `ClassNotFoundException` while running the program because the terminal was pointing to the wrong project directory.

## 🔧 How I Solved Them

- Used `balance = balance + Deposit` to update the balance.
- Used a `while` loop to keep the ATM running until Exit is selected.
- Used a nested `if` condition to check the balance before withdrawal.
- Navigated to the correct project directory before compiling and running the Java program.
